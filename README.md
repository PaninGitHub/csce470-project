# Vacation Finder (CSCE 470)

Setup (Linux/macOS, Python 3.10+): `./setup.sh`
On Windows, run the same steps manually:
`python -m venv .venv`, activate it, `pip install -r requirements.txt`,
`python scripts/collect_airbnb.py`, `python scripts/analyze.py`.

Layout: `scripts/` data collection + analysis, `figures/` plots, `data/` (git-ignored, generated).
